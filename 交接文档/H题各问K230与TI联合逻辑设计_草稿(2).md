# H题各问K230与TI联合逻辑设计

> 本文只记录已确认的系统分工、控制流程、问题和解决思路。具体参数必须通过装机实验确定。

## 一、总体职责划分

### 1. K230职责

K230负责把摄像头图像转换为尽可能真实、连续的一维钢球状态：

```text
采集图像
→ YOLO检测钢球
→ ROI、类别、置信度、框尺寸和跳变过滤
→ 确认连续检测框属于同一钢球
→ 球心投影到摆杆一维坐标
→ 位置滤波和速度估计
→ 对视觉及传输延迟进行短时预测
→ 发送位置、预测位置、速度和数据状态
```

K230内部的三帧`ACQUIRE`确认解决的是“画面中的检测框能否建立为钢球轨迹”。它持续运行，不需要知道TI何时按下启动键。

K230不负责当前题号、目标位置、摆杆电机动作和小车运动阶段。

### 2. TI职责

TI负责：

```text
读取启动按键和题目模式
→ 隔离按键前后的数据
→ 确认本轮启动数据有效
→ 设置钢球控制目标
→ 根据位置和速度计算目标摆杆角度
→ 控制摆杆电机跟踪角度
→ 控制小车循迹、加速和行驶
→ 完成计时、阶段切换和安全保护
```

TI信任K230提供的位置和速度，不再建立第二套图像滤波器；但仍检查校验、帧序号、数据新鲜度、跟踪状态和真实测量标志。

### 3. 两种“目标”不能混淆

- K230确认的视觉目标：画面中哪个检测框是钢球。
- TI设置的控制目标：把钢球控制到`0 mm`、`+50 mm`或`-50 mm`。

K230内部确认视觉目标，TI根据题目确定控制目标，职责并不冲突。

## 二、K230与TI通信数据的用途

通信协议保持：

```text
@B,seq,time,valid,state,pos,pred,v,conf,measured*CS\n
```

关键字段含义：

| 字段 | 用途 |
|---|---|
| `seq` | K230视觉帧序号，TI据此区分新旧数据和按键前后数据 |
| `time` | K230时间戳，用于检查数据年龄和日志对齐 |
| `valid/state` | 轨迹是否有效，以及处于`ACQUIRE/TRACK/HOLD/LOST`等状态 |
| `pos` | 最新真实检测校正后的当前位置估计，不是未经处理的原始框中心 |
| `pred` | 在`pos`基础上对系统延迟进行补偿后的短时预测位置 |
| `v` | K230根据连续帧得到的钢球速度估计 |
| `measured` | 本次状态是否得到了真实检测帧更新 |
| `conf` | 检测置信度，主要用于状态检查和日志分析 |

一条协议同时发送`pos`、`pred`和`v`，不需要把“实际帧”和“预测帧”拆成两条消息。

动态控制可以使用加权位置：

```text
control_pos = pos + W × (pred-pos)
```

到达、折返和最终稳定判定必须使用真实测量对应的`pos`，不能用`pred`提前宣布完成。

## 三、两级三帧确认与共同启动逻辑

### 1. K230内部三帧确认

K230在发现新候选目标时检查连续三帧的位置、框尺寸和运动关系，确认后进入`TRACK`。这负责排除首帧误检和不连续检测框。

### 2. TI启动后三帧确认

按键前K230已经热机，裁判可能正在移动钢球或遮挡摄像头。按键瞬间，TI执行：

```text
启动计时
记录按键时最后收到的seq
清空积分、历史误差和任务阶段
不继承按键前的v和pred
只统计按键后收到的新数据
```

K230内部可能仍有按键前已经曝光、但尚未完成发送的流水线帧。因此按键后先丢弃可配置数量的新帧，再开始三帧确认：

```text
START_DISCARD_FRAMES = 1    # 第一版暂定值
```

该参数必须保留醒目标记，后续根据端到端延迟测试在`1～3帧`范围内核实。被丢弃的帧不参与位置、速度、目标锁定和确认计数。

TI不重新识别钢球，只确认按键后的K230状态能否用于本轮任务。连续确认条件为：

```text
seq确实更新
measured=1
K230轨迹状态有效
相邻帧位移符合物理可能性
```

第3～5问还要求位置位于O点启动范围；第6问不预设位置，只要求三帧位置稳定并位于摆杆物理有效范围。

连续三个按键后的真实测量满足条件，TI进入正式运动阶段。条件不满足时清零或重新开始计数。

第3～6问统一在确认期间保持静止：

```text
小车驱动保持停止
预测权重W=0
不开放积分、大角度动作和车辆启动
```

只保持固定机械零角度可能因车体、场地或机构不完全水平而让钢球缓慢漂移。因此确认期间采用低权限启动保持：

- 以标定的`theta_neutral`作为基础角度。
- 第3～5问以O点作为临时保持目标。
- 第6问用丢弃保护帧后的第一帧合法`pos`建立临时候选目标。
- 只使用真实`pos`和小幅速度阻尼，`W=0`、积分关闭。
- 摆杆角度和角度变化率采用比正式运行更严格的限幅。

该控制只用于阻止三帧期间的缓慢漂移，不负责正式运动。若数据异常，摆杆回到`theta_neutral`，车辆继续保持停止。

启动确认必须设置最大等待时间。超过等待上限仍未确认时，保持车辆停止和摆杆安全状态并报告启动失败，不能带着未确认的钢球状态进入正式运动。

## 四、共同控制结构

### 1. 位置和速度必须共同参与控制

距离误差决定钢球应该向哪里运动，速度决定现在应该继续加速还是提前制动。只按位置控制会产生明显过冲，只按速度控制则不知道最终目标。

推荐采用串级结构：

```text
位置误差
→ 期望钢球速度
→ 目标摆杆角度
→ 摆杆电机角度闭环
```

概念关系为：

```text
v_target = Kpos × (target-control_pos)

theta_target
= Kvel × (v_target-v)
+ theta_vehicle_feedforward
```

所有目标速度、摆杆角度和角度变化率均需限幅。

摆杆电机必须能够可靠跟踪`theta_target`。可以使用带位置控制的舵机、电机编码器或摆杆角度传感器形成内环；不宜仅用无反馈PWM直接代表摆杆角度。

TI还必须监测执行器是否真正跟随命令：

```text
angle_error = theta_target - theta_actual
```

如果角度反馈无效、实际角度未向命令方向变化，或`angle_error`连续超过允许范围，则判定为执行器跟随故障：

- 立即停止积分并禁止继续增大摆杆命令。
- 第3问终止任务并保持可实现的安全角度。
- 第4～6问让车辆平滑减速，不能突然急刹或直接切断所有控制。
- 记录目标角度、实际角度、限位状态和故障持续时间。
- 故障锁存到人工按键结束或复位，不能自行反复进入正常运行。

### 2. 预测权重W的原则

`pred`适合补偿平稳运动中的延迟，但固定全权使用会在制动、换向和目标附近放大速度估计误差。

推荐：

```text
平稳单向运动：W较大
开始制动或摆杆作用方向反转：立即降低W_target，实际W平滑下降
钢球速度接近零：保持低W
明确确认钢球反向：W恢复到中等值
新方向继续稳定：W恢复正常值
目标附近精细平衡：W较小，以pos和v为主
```

`W`不采用瞬时分段跳变，而是由实时目标值`W_target`和连续变化器生成：

```text
W_next = W_now + clamp(W_target-W_now,
                       -W_fall_rate×dt,
                       +W_rise_rate×dt)
```

也可使用等价的一阶渐变。TI不需要预知当前阶段会持续多久：当前运动状态只决定`W_target`，实际`W`从当前值连续追向最新目标；如果状态中途再次改变，就从当时的`W`平滑转向新目标。

降低预测可以较快，恢复预测应较慢，即通常令下降速率大于上升速率。最终摆杆目标角度仍需变化率限制，形成第二层无扰保护。

摆杆电机换向不等于钢球已经换向，不能规定“电机换向两帧后恢复预测”。应观察K230给出的真实钢球状态。

如果一个真实测量帧已经给出幅值明显、且与位置变化一致的反向速度，TI可以立即确认换向并恢复部分预测，不必再固定等待两帧。只有速度接近零、符号可能由噪声造成时，才继续等待更明确的趋势。

### 3. 防止预测和速度项重复补偿

由于`pred-pos`本身主要来自速度外推，增大`W`相当于加强速度制动。因此`W`与速度反馈增益必须共同调节：

- `W`较大时，额外速度阻尼不宜过强。
- `W`较小时，可以更多依靠速度反馈。
- 目标附近优先使用`pos+v`，避免过度预测造成来回摆动。

## 五、统一视觉异常处理

### 1. 单帧丢失

K230短时预测并设置`measured=0`。TI可以有限使用预测维持控制，但不得用该帧完成到达、折返或稳定判定。

### 2. 连续丢失

```text
短时丢失：保持有限控制
继续丢失：不再增大输出，逐步降低预测信任度
进入LOST：摆杆向安全小倾角或水平位置收敛，暂停阶段切换
重新识别：先使用真实pos，状态稳定后再恢复速度和预测权重
```

车辆正在行驶时不能因视觉失联突然急刹，应使用平滑减速，避免急刹产生更大的钢球惯性扰动。

### 3. 单帧误检

K230负责ROI、框大小、轨迹连续性和跳变拒绝。TI不分析图像框，但启动和阶段切换必须检查位置是否符合本题物理范围，且不使用单帧异常数据改变任务状态。

## 六、第3问：小车静止，O→+5 cm→-5 cm

### 1. 任务流程

```text
小车保持静止
→ 钢球从O点向+50 mm运动
→ 提前制动
→ 确认到达+50 mm
→ 折返向-50 mm运动
→ 提前制动
→ 稳定在-50 mm
→ 停止计时但继续闭环保持
```

实际目标始终为题目规定的`+50 mm`和`-50 mm`。`±4.x cm`只能作为可能的动态制动起点，不能替代标定目标。

### 2. 启动

第3问已知钢球初始位于O点，初始运动方向确定为正方向。

按键后：

```text
TI隔离按键前数据并开始三帧启动确认
小车保持静止，摆杆使用低权限O点保持
三帧确认钢球位于O点附近且速度接近0
确认成功后将目标设为+50 mm
切入位置—速度完整闭环并开始推动钢球
```

启动确认时间计入题目5 s总时间。三帧本身约需100～150 ms，第一版再丢弃一帧后总启动等待暂按约150～200 ms估计，必须在整机调参时预留时间余量；它换取了确定的初始状态，并取消了确认期间的盲目正向起步力。

### 3. 向+50 mm运动与提前制动

距离较远时允许较高目标速度；接近目标时降低目标速度。预计剩余滑行距离可按以下因素确定：

```text
当前速度对应的制动距离
+ 视觉和机构延迟期间继续运动的距离
+ 少量安全裕量
```

当剩余距离接近预计滑行距离时，TI开始施加反向摆杆角度。球越快，制动越早；球越慢，制动越晚。因此制动点不能固定为某个`4.x cm`数值。

### 4. 到达+50 mm与折返

`4.x cm`只表示可能开始制动，只有真实测量位置进入+50 mm允许范围，才说明完成了“到达+5 cm”的要求。

若钢球高速穿过+50 mm，说明前一阶段制动偏晚，不能将其视为理想到达。下一轮应调整速度规划和制动距离。

到达后：

```text
目标切换为-50 mm
清除正向阶段积累的积分
保留钢球真实速度
限制摆杆命令变化率
继续动态计算摆杆角度
```

摆杆开始反向不代表钢球已经反向。制动期间降低`W`，继续根据`pos`和`v`调整角度；只有检测到明确反向速度后，才恢复新方向的预测权重。

### 5. 向-50 mm运动

负向运动采用相同的位置—速度控制结构，但正反方向的机械死区、摩擦和加速度响应可能不同，必须分别标定。

接近-50 mm时使用动态制动。`-4.x cm`可能是制动起点，最终控制目标仍为`-50 mm`。

### 6. 最终稳定和计时

进入-50 mm附近后切换为小范围平衡控制。完成判定必须同时满足：

```text
measured=1且轨迹有效
真实位置位于-50 mm允许误差内
钢球速度足够小
上述状态连续保持一段时间
```

单帧进入范围、预测帧进入范围或高速穿过目标均不能停止计时。完成后只停止任务计时，仍以`-50 mm`为目标继续闭环，防止球再次移动。

### 7. 第3问需要装机标定

- O点启动合法范围。
- 三帧启动确认的稳定范围和最大等待时间。
- 位置误差到目标速度的映射。
- 速度误差到摆杆角度的映射。
- 正反方向摆杆死区和最大角度。
- 不同速度下的实际制动距离。
- 制动、换向和稳定阶段的预测权重。
- 最终速度门限和稳定持续时间。

## 七、第4问：A点启动，经AB并通过B，钢球稳定在O点

### 1. 任务流程

```text
小车位于A点，钢球位于O点
→ 按键启动并开始计时
→ 小车静止完成三帧启动确认
→ 小车平滑加速
→ 摆杆同步施加车辆惯性前馈
→ AB直线段稳定循迹和匀速行驶
→ 通过B点后继续循迹并保持钢球稳定
```

AB长度为1.5 m，时间要求为8 s，平均速度只需达到约`0.1875 m/s`，因此没有必要猛加速。平滑启动比追求极限速度更重要。

### 2. 启动与预设补偿

按键后小车先保持静止，TI完成三帧O点确认；确认期间摆杆使用无预测、无积分、小角度限幅的O点保持，不启动车辆，也不施加车辆惯性前馈。

确认成功后，小车才开始平滑加速。小车向前加速时，钢球受到相对惯性扰动。若等视觉看到钢球偏离后才控制，会损失视觉延迟时间，因此TI在启动小车的同时，根据车辆加速命令预先施加摆杆补偿：

```text
摆杆控制
= 车辆启动前馈
+ 钢球位置反馈
+ 钢球速度反馈
```

正式启动阶段：

```text
小车按平滑加速斜坡启动
摆杆使用预设、限幅的惯性补偿
视觉位置—速度闭环同步工作
```

预设补偿不可能在所有场地、电池电压和摩擦条件下完全准确，因此它只负责车辆加速阶段的前馈，不能代替视觉闭环。为保证鲁棒性：

- 小车启动PWM使用斜坡，不突然全力输出。
- 摆杆前馈跟随小车加速命令变化，不使用一次性的猛烈固定脉冲。
- 前馈宁可略小，剩余误差由视觉闭环纠正。
- 前馈和摆杆角度均限幅，最坏情况下也不能主动造成明显偏移。
- 如果有可靠轮速反馈，后续可利用实际轮速变化修正车辆加速度前馈。

### 3. AB段稳定行驶

小车进入近似匀速后，持续纵向惯性扰动明显减小，车辆加速前馈逐渐回到零，钢球主要依靠位置—速度闭环保持在O点。

题目的`±1 cm`是评分边界，不应作为正常纠偏起点。内部控制应尽量把正常波动压在更小范围，接近边界前就明显加强纠正。

循迹控制也必须平滑：左右轮PWM频繁大幅变化、车身摇摆和机械振动都会转化为钢球扰动。车辆速度规划与摆杆控制需要同时调试，不能分别在完全不同的运动条件下独立定参。

### 4. 车辆频繁改变控制方向时的预测

第四问目标固定为O点，摆杆可能在零点附近频繁正反调整。如果始终使用较大`W`，速度估计和预测可能放大抖动。

因此：

```text
明显单向偏移时：适量使用pred补偿延迟
开始反向纠正时：降低W
速度接近零时：保持低W
确认新方向后：仅按需要恢复部分W
O点附近稳定控制：以pos和v为主，W保持较小
```

摆杆角度始终连续计算，不会因等待钢球换向而固定不动。明确的反向速度一帧即可响应；只有零速附近的模糊符号才需要继续观察。

### 5. 单帧和连续丢失

- 单帧丢失：短时使用K230预测，降低控制激烈程度，不改变任务阶段。
- 连续丢失：逐步收小摆杆输出，同时让小车平滑减速。
- 进入LOST：摆杆趋向安全位置，小车继续平滑减速而不是急刹。
- 恢复识别：先使用真实`pos`，确认稳定后再恢复速度和预测。

### 6. 通过B后的逻辑

当前方案不在B点切换控制状态，也不突然停车：

```text
继续循迹
继续保持钢球O点闭环
继续处理视觉异常和通信保护
```

后续如果需要增加减速或停车，应放在确认通过B之后，并使用平滑速度规划，不能在B点产生突然加减速。当前版本无需依赖B点标志完成摆杆控制状态切换。

### 7. 第4问需要装机标定

- 三帧O点确认范围和最大等待时间。
- 小车启动加速斜坡。
- 车辆加速命令到摆杆补偿角度的映射和方向。
- 满电、低电及不同地面条件下的前馈偏差。
- O点附近位置—速度控制参数。
- 正反向纠正时的预测权重变化。
- 正常内部误差带和接近评分边界时的加强策略。
- 视觉连续丢失时的小车减速斜坡和摆杆安全角度。

## 八、第5问：顺时针一圈，钢球稳定在O点

### 1. 与第4问的关系

第5问直接复用第4问的钢球平衡主体：

```text
目标始终为0 mm
启动后三帧确认
车辆启动惯性前馈
位置—速度—摆杆角度串级控制
动态预测权重W
漏检、失联和恢复保护
```

新增部分来自完整路线：

```text
A→B直线
→ B→C半圆弯道
→ C→D直线
→ D→A半圆弯道
→ 再次通过A点
```

因此第5问不是更换钢球控制器，而是在第4问基础上增加弯道扰动、整圈车速规划和A点完成判断。

### 2. 启动和直线段

启动逻辑与第4问相同：按键后小车先静止完成三帧O点确认；确认成功后，小车才按平滑加速斜坡起步，摆杆同步施加车辆惯性前馈并保持完整视觉闭环。

直线近似匀速阶段逐渐撤除车辆加速前馈，以K230的`pos`和`v`维持O点稳定。钢球状态正常时按规划速度循迹；位置偏差或速度明显增大时，暂停继续加速或平滑降低车辆速度。

### 3. 弯道扰动

弯道会产生与车速和转弯半径有关的侧向加速度。它对钢球一维运动的实际影响取决于摆杆轴线在车体上的安装方向：

- 摆杆沿车身前后方向时，侧向加速度的直接投影较小，但车身摇摆和轮速修正仍会扰动钢球。
- 摆杆沿车身左右方向时，弯道侧向加速度会成为主要扰动。
- 摆杆斜向安装时，纵向和侧向加速度都会产生沿摆杆方向的分量。

第一版不必进行复杂姿态解算，可依据左右轮命令、车速和循迹状态建立经验弯道前馈，再由视觉闭环修正剩余误差：

```text
theta_target
= 钢球位置速度闭环
+ 车辆纵向加速前馈
+ 弯道经验前馈
```

弯道前馈的具体触发来源、参数和实现由TI控制组结合循迹、电机及编码器方案确定；K230接口不增加题目或弯道状态字段，只持续提供统一钢球状态。

### 4. 进入和离开弯道

相比稳定过弯，直线与弯道之间的状态变化更容易造成钢球偏移。小车应采用：

```text
进入弯道前平滑降低速度
弯道内保持较稳定的中低速度
离开弯道后平滑恢复直线速度
```

左右轮PWM不能突然大幅变化。弯道前馈也应平滑加入和撤除，避免前馈本身成为新的扰动。

题目允许整圈30 s，因此优先保证钢球稳定，不需要用激烈加减速追求极限时间。

### 5. 钢球状态对车辆速度的约束

循迹方向仍由红外光电模块决定，钢球状态只作为车辆速度上限的监督量：

```text
钢球接近O点且速度较小：按规划速度运行
钢球偏差或速度增大：不再继续加速
钢球明显偏离：平滑降低车辆速度
视觉连续丢失：进入安全减速
```

不能因钢球单帧坐标波动立即改变左右轮方向，也不能因失联突然急刹。

### 6. 弯道和频繁纠正时的预测权重

第五问沿途扰动比第四问更多，但预测使用原则不变：

```text
钢球明显单向偏移：适当增大W
摆杆开始反向纠正：降低W
钢球速度接近零：保持低W
确认新方向后：按需要恢复W
O点附近稳定：以pos和v为主
```

弯道前馈用于提前抵消可预见扰动，K230预测用于补偿钢球状态延迟，两者作用不同，调参时需要防止共同补偿过强。

### 7. 一圈完成判断

A点存在横向启停线。TI必须区分启动时经过A线和完成一圈后再次经过A线：

```text
按键启动并离开A点
→ 达到最小离开时间或距离
→ 开启终点A线检测
→ 再次检测到A线
→ 认定完成一圈并停止计时
```

可以叠加足够行驶距离或路线阶段信息，防止车体在起点附近抖动时误判完成一圈。

通过A点后不突然改变摆杆角度或急刹：

```text
停止本题计时
继续循迹
继续保持钢球O点闭环
后续如需停车，再执行独立的平滑减速流程
```

### 8. 第5问需要装机标定

- 直线和弯道的车辆规划速度。
- 进入、离开弯道的速度斜坡。
- 左右轮命令或轮速到弯道摆杆前馈的映射。
- 不同车速下的弯道扰动程度。
- 钢球偏差、速度与车辆限速等级的关系。
- A点终点检测的启用距离、时间和去重条件。
- 弯道状态下的预测权重与速度反馈参数。

## 九、第6问：任意指定位置保持一圈

### 1. 与第5问的关系

第6问没有增加新的物理自由度，钢球仍然只有沿摆杆方向的一维位置。它与第5问的区别只是控制目标由固定O点变为启动时锁定的任意初始坐标：

```text
第5问：target = 0 mm
第6问：target = target_lock
```

目标锁定后，启动前馈、直线和弯道控制、动态预测权重、车辆限速、视觉异常保护以及A点整圈判断全部复用第5问。

### 2. 开局静止锁定目标

第6问不知道裁判指定位置的数值，因此不能像第4、5问那样在确认视觉的同时立即启动车辆。正确顺序为：

```text
按键启动并开始计时
→ 小车保持静止
→ 第一帧合法位置后启用低权限临时保持
→ TI只统计按键后的新真实测量
→ 连续三帧位置有效且稳定
→ 锁定任意目标坐标
→ 再平滑启动车辆
```

三帧锁定本身约消耗100～150 ms；第一版丢弃一帧后总启动等待暂按约150～200 ms估计，相对于30 s整圈时间仍很小，可以避免车辆启动惯性和流水线旧帧污染初始目标。

有效锁定条件为：

```text
三个不同的新seq
measured=1
K230轨迹状态有效
三帧位置波动较小
速度接近零
不存在跳变拒绝或连续丢失
```

任何一帧不满足条件，则重新开始三帧计数。若在合理等待时间内始终无法获得稳定目标，TI不启动车辆并提示启动失败，不能带着未确定目标进入赛道。

### 3. 目标计算和永久冻结

目标使用三帧真实`pos`的中值或稳健平均值：

```text
target_lock = median(pos1, pos2, pos3)
```

静态目标不能使用`pred`计算。锁定完成后：

```text
target = target_lock
```

并在本轮任务中永久冻结。钢球偏移、单帧丢失、进入HOLD/LOST或重新识别都不能修改目标，否则目标会跟随钢球漂移，使控制误差被错误清零。

锁定目标后，TI清除旧速度使用状态、积分和历史误差，但保留`target_lock`，再执行与第5问相同的小车平滑启动和摆杆惯性前馈。

### 4. 整圈运行

运行阶段统一使用：

```text
error = target_lock - control_pos
```

之后直接进入第5问的完整逻辑：

- 位置误差生成目标钢球速度。
- 速度误差生成目标摆杆角度。
- 叠加车辆纵向加速和弯道前馈。
- 根据制动、换向和稳定状态动态调整`W`。
- 根据钢球偏差和速度限制车辆最高速度。
- 视觉丢失时执行摆杆保护和车辆平滑减速。
- 再次通过A点后停止计时，但继续保持`target_lock`闭环。

### 5. 边缘位置

任意目标可能比O点更接近摆杆端部，这不需要为第6问建立另一套控制器，而是对同一套控制质量提出更高要求：

- K230端部坐标映射和ROI必须准确。
- 摆杆角度内环、速度估计和预测权重必须足够稳定。
- 正反向死区和机构间隙不能造成明显不对称。
- 通用角度限幅和机械边界保护必须有效。

装机测试应覆盖中心、正负中间位置和靠近两端的位置，验证同一套参数是否能够满足要求。若不同位置确实表现不一致，可做连续的小范围增益修正，但不改变总体控制结构。

### 6. 第6问需要装机标定

- 三帧位置波动和静止速度门限。
- 目标锁定最长等待时间。
- 任意位置的视觉测量重复性。
- 中心、两侧及靠近端部位置的闭环误差。
- 端部机械安全限制。
- 不同目标位置下的车辆启动和弯道前馈效果。

## 十、摆杆角度标定方法

### 1. 水平零点

小车静止，将钢球放在O点，寻找钢球不持续向某侧滚动时的摆杆命令，得到真实`theta_zero`。机械中值不一定等于水平零点。

### 2. 角度—加速度关系

在小车静止时分别施加若干正、负小角度，利用K230记录的`pos`和`v`计算钢球加速度，得到：

```text
a_ball ≈ Ktheta × (theta-theta_zero)
```

正负方向分别拟合，同时记录死区、摩擦和最大安全角度。理论上小角度内近似线性，但最终以实测为准。

### 3. 制动能力

让钢球以不同速度运动，施加不同反向角度，记录停止时间和停止距离，用于确定第3问的速度规划、提前制动距离和最大制动角度。

### 4. 第4问车辆前馈

让小车采用固定加速斜坡启动，逐步调节摆杆前馈，使启动阶段钢球偏移最小；随后在不同电池电压和地面条件下验证，保证即使前馈存在偏差，视觉闭环仍能及时修正。

## 十一、三至六问实施完整性审查

### 1. K230与TI控制频率不同

K230约以20 Hz更新视觉状态，而TI的摆杆角度内环和车辆电机控制应以更高频率运行。TI只在`seq`更新时接收一次新的钢球状态，不能把同一个协议包重复当作多次新测量：

```text
新seq到达：更新pos、pred、v和外环目标角度
两帧之间：保持或平滑过渡目标角度
高速内环：持续控制电机跟踪目标角度
```

速度、微分和积分更新必须使用真实时间间隔，不能假定每帧严格等于50 ms。

### 2. 通信与数值有效性

TI使用K230数据前统一检查：

```text
校验正确
seq确实更新
时间戳和接收时间足够新
pos、pred、v位于物理合理范围
state和measured语义一致
```

重复帧不得重复积分；错误帧直接丢弃；通信超时按视觉失联处理。恢复后先使用真实`pos`，不能立即继承失联期间的预测历史。

### 3. 坐标、方向和单位统一

装机后必须一次性确认：

- 图像坐标增大对应摆杆物理正方向。
- 正摆杆角度确实产生正方向钢球加速度。
- 车辆启动和弯道前馈的符号正确。
- 协议中的位置、速度和时间统一使用约定单位。

任何一处符号反转都会使闭环由负反馈变为正反馈，因此必须通过低幅度静态测试确认后才能整车运行。

### 4. 限幅、变化率和积分保护

所有题目共同需要：

```text
目标钢球速度限幅
目标摆杆角度限幅
摆杆角度变化率限制
电机输出限幅
积分抗饱和
阶段切换、失联和任务重启时按规则清积分
```

达到限幅时必须记入日志，便于判断问题来自控制参数还是机构能力不足。

### 5. 完成判定与完成后的行为

- 第3问完成后只停止计时，继续保持`-50 mm`。
- 第4问通过B后继续循迹并保持O点。
- 第5问通过A后停止计时，但继续循迹并保持O点。
- 第6问通过A后停止计时，但继续循迹并保持`target_lock`。

不能把“停止计时”直接等同于关闭电机或退出钢球闭环。

### 6. 稳定优先与时间余量

车辆因钢球偏差减速时仍要保证第4问8 s和第5、6问30 s的时间要求。调试时应选择留有余量的正常车速，而不是正常状态恰好压线、发生一次减速就超时。

车辆速度监督采用持续时间或迟滞，避免钢球坐标单帧波动造成车辆速度频繁升降。

### 7. 实跑日志必须能够解释失败原因

日志属于调测功能，比赛正式版本可以关闭；无论开启与否，都必须低于识别、通信和电机控制优先级。日志采用缓存和批量写入，写盘失败或耗时过长时允许自动停用，不能阻塞实时控制。

调测时K230与TI日志至少应能对齐并还原：

```text
seq和两端时间
任务状态和target
pos、pred、v、measured、state
预测权重W
目标摆杆角度和实际角度
角度限幅、积分和失联状态
左右轮命令或轮速
循迹状态、车辆速度阶段和A线检测
每次阶段切换、目标锁定和停止计时原因
按键START、STOP和人工ABORT事件及其时间戳
```

这样才能区分视觉误差、预测过量、摆杆响应不足、车辆扰动、通信异常和状态机误判。

### 8. 上场前统一自检

每轮正式测试前至少确认：

```text
K230模型和摄像头正常
UART持续收到新seq
摆杆零角度和正负方向正确
钢球位置处于本题允许初始状态
角度执行器没有顶死
第6问target_lock已经成功生成
```

自检失败时不允许进入正常车辆启动状态。

### 9. 预测提前量必须按端到端延迟标定

K230约43～45 ms的模型推理时间不等于钢球真实运动到TI得到坐标的总延迟。实际还包括摄像头曝光、传感器和显示/采集缓冲排队、预处理、协议发送及TI接收调度。

预测时间必须通过运动钢球的端到端实验标定，并观察`pos`、`pred`和真实运动之间的关系。推理时间只能作为其中一部分，不能直接设置为完整预测提前量。

### 10. 状态切换需要迟滞和持续条件

制动、换向、稳定、车辆限速和恢复正常速度等状态不能由单帧跨阈值触发。应使用速度死区、进入/退出不同阈值或最短持续时间，避免坐标在门限附近抖动导致状态频繁切换。

第3问的到达和稳定、第5、6问的车辆限速以及所有题目的LOST恢复都应遵循这一原则。

### 11. 相机、摆杆和执行器的结构一致性

像素到毫米映射成立的前提是摄像头与摆杆相对位置固定。装车后应防止相机支架、摆杆铰链和电机连接松动，并在每次重新装配后检查O点坐标、两端坐标和摆杆零角度。结构发生位移时必须重新标定，不能仅靠软件滤波弥补。

摆杆上下运动会引入透视和投影变化。第一版暂不做角度相关修正，但必须保留醒目待核实标记：在零角度、最大正角度和最大负角度下，用摆杆上的五个已知位置测量K230坐标误差。若误差达到影响控制的量级，再决定是否增加角度相关映射。

镜头本身的径向畸变继续由K230标定项负责，本节只核实摆杆上下运动产生的几何变化。

### 12. 按键、终止和多轮任务

同一任务按钮采用明确的边沿事件和消抖：

```text
IDLE第一次按下：START，开始计时并进入启动确认
START_VERIFY或RUN再次按下：人工STOP/ABORT
DONE或FAULT：等待人工复位后回到IDLE
```

人工终止时先记录结束时间和原因。第4～6问车辆执行平滑减速，摆杆继续保持钢球控制直至车辆安全停止；不能把第二次按键直接实现为所有电机瞬间断开。

每轮任务用START和STOP/完成事件的时间戳分割日志。进入新一轮前清空旧积分、确认计数、完成标志、A线去重状态和第6问`target_lock`，但不影响K230持续识别。
