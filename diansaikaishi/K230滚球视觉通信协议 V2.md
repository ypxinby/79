# K230滚球物理坐标通信协议 V2

> 状态：冻结，可用于K230与MSPM0G3507并行开发  
> 日期：2026-07-31  
> 发送端：K230视觉程序  
> 接收端：MSPM0G3507下位机  
> 串口：115200，8N1，3.3V TTL

## 1. 冻结结论

摄像头固定在水管上方，K230负责完成图像坐标到物理距离的换算。K230只发送小球相对水管中心O的当前位置，单位固定为毫米。

```text
O点       =   0 mm
题目+5cm  = +50 mm
题目-5cm  = -50 mm
```

正方向必须与题目物理标记的`+5cm`方向一致。K230不发送PID输出、步进位置或水管角度。

MSPM0负责：

```text
任务目标生成
位置误差计算
小球PD外环
步进编码器位置内环
软件限位、失联和故障保护
```

V2与旧像素V1语义不兼容。MSPM0只接受`version=0x02`，旧V1帧会被计为版本错误，不会更新控制坐标。

## 2. 接线

```text
K230 TX  → MSPM0 PB3（UART_VISION RX）
K230 RX  ← MSPM0 PB2（V2暂不要求连接）
K230 GND ↔ MSPM0 GND
```

双方必须共地并使用3.3V TTL电平。

## 3. 发送周期

```text
推荐：50 Hz，每20 ms一帧
可接受：25～50 Hz
```

检测不到小球时仍须按相同频率发送合法无目标帧。不能停止发送，也不能沿用最后一次坐标。

## 4. 固定40字节帧

所有多字节整数均为小端序。

| Offset | 长度 | 类型 | 字段 | V2规则 |
| ---: | ---: | --- | --- | --- |
| 0 | 1 | `uint8` | `magic_0` | 固定`0xA5` |
| 1 | 1 | `uint8` | `magic_1` | 固定`0x5A` |
| 2 | 1 | `uint8` | `version` | 固定`0x02` |
| 3 | 1 | `uint8` | `message_type` | 固定`0x01` |
| 4 | 1 | `uint8` | `flags` | 见第5节 |
| 5 | 1 | `uint8` | `reserved` | 固定`0x00` |
| 6 | 2 | `uint16` | `payload_length` | 固定`30` |
| 8 | 4 | `uint32` | `session_id` | 每次K230程序启动生成新的非零值 |
| 12 | 2 | `uint16` | `sequence` | 每发送一帧加1，允许65535回绕到0 |
| 14 | 4 | `uint32` | `timestamp_ms` | K230程序启动后的单调毫秒数 |
| 18 | 2 | `uint16` | `axis_span_mm` | 水管以O为中心的有效总长度，范围`1～5000mm` |
| 20 | 2 | `uint16` | `profile` | 固定`1` |
| 22 | 2 | `int16` | `ball_position_mm` | 相对O点带符号位置 |
| 24 | 2 | `uint16` | `position_reserved` | 有目标固定`0`，无目标固定`0xFFFF` |
| 26 | 2 | `uint16` | `confidence` | 有目标`0～1000`，无目标`0` |
| 28 | 2 | `uint16` | `target_id` | 固定`0xFFFF` |
| 30 | 2 | `uint16` | `reserved_0` | 固定`0` |
| 32 | 2 | `uint16` | `reserved_1` | 固定`0` |
| 34 | 2 | `uint16` | `reserved_2` | 固定`0` |
| 36 | 2 | `uint16` | `reserved_3` | 固定`0` |
| 38 | 2 | `uint16` | `crc16` | 对offset 0～37计算，小端存放 |

有效位置必须满足：

```text
abs(ball_position_mm) × 2 <= axis_span_mm
```

例如有效总长度为300mm时，合法位置范围为`-150～+150mm`。

## 5. flags

| Bit | 名称 | V2含义 |
| ---: | --- | --- |
| 0 | `TARGET_VALID` | 当前检测到有效小球 |
| 1 | `HAS_BBOX` | 固定为0 |
| 2 | `HAS_TARGET_ID` | 固定为0 |
| 3 | `HAS_CONFIDENCE` | 有目标时固定为1 |
| 4 | `SOURCE_RESTART` | K230程序刚启动 |
| 5～7 | Reserved | 固定为0 |

推荐值：

```text
正常有目标：0x09
启动前3帧有目标：0x19
正常无目标：0x00
启动前3帧无目标：0x10
```

## 6. 有效位置帧

示例：

```text
session_id      = 0x12345678
sequence        = 0
timestamp_ms    = 1000
axis_span_mm    = 300
ball_position_mm= +50
confidence      = 900
flags           = 0x09
```

完整HEX：

```text
A5 5A 02 01 09 00 1E 00
78 56 34 12 00 00 E8 03 00 00
2C 01 01 00 32 00 00 00
84 03 FF FF 00 00 00 00 00 00 00 00
49 17
```

CRC为`0x1749`，帧尾小端发送`49 17`。

`-50mm`在`int16`中编码为`0xFFCE`，小端字节为`CE FF`。

## 7. 无目标帧

无目标时：

```text
TARGET_VALID=0
ball_position_mm原始字段=0xFFFF
position_reserved=0xFFFF
confidence=0
target_id=0xFFFF
其余保留字段=0
```

示例完整HEX：

```text
A5 5A 02 01 00 00 1E 00
78 56 34 12 01 00 FC 03 00 00
2C 01 01 00 FF FF FF FF
00 00 FF FF 00 00 00 00 00 00 00 00
66 23
```

无目标的判断以`TARGET_VALID`为准。有效位置`-1mm`的原始字节同样为`FF FF`，但其`TARGET_VALID=1`且`position_reserved=0`，不会产生歧义。

## 8. CRC

```text
CRC-16/CCITT-FALSE
poly   = 0x1021
init   = 0xFFFF
refin  = false
refout = false
xorout = 0x0000
范围   = 帧offset 0～37，共38字节
存储   = 小端
```

```python
def crc16_ccitt_false(data):
    crc = 0xFFFF
    for byte in data:
        crc ^= byte << 8
        for _ in range(8):
            if crc & 0x8000:
                crc = ((crc << 1) ^ 0x1021) & 0xFFFF
            else:
                crc = (crc << 1) & 0xFFFF
    return crc
```

## 9. K230打包参考

```python
import random
import struct

HEADER = struct.Struct("<2sBBBBH")
PAYLOAD = struct.Struct("<IHIHHhHHHHHHH")

FLAG_TARGET_VALID = 1 << 0
FLAG_HAS_CONFIDENCE = 1 << 3
FLAG_SOURCE_RESTART = 1 << 4


def build_ball_frame(session_id, sequence, timestamp_ms,
                     axis_span_mm, ball_position_mm,
                     confidence, valid,
                     source_restart=False):
    if valid:
        if abs(ball_position_mm) * 2 > axis_span_mm:
            raise ValueError("ball position outside axis span")
        flags = FLAG_TARGET_VALID | FLAG_HAS_CONFIDENCE
        position_field = int(ball_position_mm)
        position_reserved = 0
        confidence = max(0, min(1000, int(confidence)))
    else:
        flags = 0
        position_field = -1       # raw uint16 = 0xFFFF
        position_reserved = 0xFFFF
        confidence = 0

    if source_restart:
        flags |= FLAG_SOURCE_RESTART

    header = HEADER.pack(
        b"\xA5\x5A", 2, 1, flags, 0, 30
    )
    payload = PAYLOAD.pack(
        session_id & 0xFFFFFFFF,
        sequence & 0xFFFF,
        timestamp_ms & 0xFFFFFFFF,
        int(axis_span_mm),
        1,
        position_field,
        position_reserved,
        confidence,
        0xFFFF,
        0, 0, 0, 0,
    )
    body = header + payload
    return body + struct.pack("<H", crc16_ccitt_false(body))
```

每次K230程序启动：

```python
session_id = random.getrandbits(32) or 1
sequence = 0
```

有效帧和无目标帧都必须递增`sequence`。启动后的前3帧设置`SOURCE_RESTART`。

## 10. K230物理标定要求

固定相机仍需在K230侧保存一次标定：

```text
O点对应的图像轴坐标
像素到毫米比例或一维映射表
题目+5cm对应的正方向
摄像头ROI及水管轴线
```

如果透视不明显，可使用线性换算；如果水管两端比例不同，应使用一维分段映射或单应性投影。摄像头高度、角度、分辨率或ROI改变后必须重新标定。

## 11. 下位机处理

```text
连续3帧有效位置：允许进入PD
超过100ms无有效位置：停止使用旧坐标，水管目标回零
超过300ms无有效位置：进入VISION_LOST
坐标单帧跳变超过门限：拒绝该帧
重新连续3帧有效位置：恢复控制输入
```

K230不需要知道当前执行题3、题4、题5还是题6：

```text
题3目标：MSPM0依次设置+50mm、-50mm
题4/5目标：MSPM0设置0mm
题6目标：MSPM0锁存启动时多帧平均位置
```
