# K230滚球有线ASCII通信协议 V3

## 1. 串口

```text
115200, 8N1, 无流控
K230 TX -> MSPM0 PB3
K230 GND -> MSPM0 GND
发送频率：20Hz
```

## 2. 唯一帧格式

```text
@B,seq,time,valid,state,pos,pred,v,conf,measured*CS\n
```

这是ASCII文本行，不是旧版40字节二进制帧。允许行尾为`\n`或`\r\n`。

| 字段 | 格式与单位 | 下位机要求 |
|---|---|---|
| `seq` | `uint16`十进制 | 每帧加1，65535后回0 |
| `time` | `uint32`十进制，ms | K230启动后的单调时间；回退视为K230重启 |
| `valid` | `0/1` | 1表示当前轨迹有效 |
| `state` | 1～11字符 | 仅允许字母、数字、`_`、`-` |
| `pos` | 有符号十进制，mm | 当前小球相对O点位置，允许最多3位小数 |
| `pred` | 有符号十进制，mm | K230预测位置，允许最多3位小数 |
| `v` | 有符号十进制，mm/s | K230估算速度 |
| `conf` | 十进制 | 可发送`0.000～1.000`或`0～1000` |
| `measured` | `0/1` | 1表示本帧包含真实视觉测量 |
| `CS` | 两位十六进制 | XOR校验，允许大小写 |

坐标规定：

```text
O点   = 0mm
+5cm  = +50mm
-5cm  = -50mm
当前水管有效总长 = 300mm
合法pos/pred范围 = -150～+150mm
合法速度绝对值 <= 3000mm/s
```

## 3. 校验和

`CS`是从`B`开始到`*`前一个字符为止，所有ASCII字节逐字节异或的结果。`@`、`*`、CS和换行不参与。

```python
body = "B,1,50,1,TRACK,20.0,21.0,5.0,0.900,1"
cs = 0
for value in body.encode("ascii"):
    cs ^= value
line = f"@{body}*{cs:02X}\n"
uart.write(line.encode("ascii"))
```

## 4. 下位机过滤规则

以下输入全部丢弃，且不会更新控制坐标：

- 缺少`@B,`、`*CS`或换行；
- 字段不是严格10项；
- XOR错误；
- 超长行、控制字符、非ASCII乱码；
- 数字溢出、非法小数、非法state；
- `valid/measured`不是0或1；
- `pos/pred`越过水管范围，或速度超过门限；
- 重复序号或旧序号。

合法帧连续3帧后，滚球PD才允许使用坐标。超过150ms没有新合法帧时停止使用旧坐标并回水平，超过400ms进入`LOST`。

BALL页面保持`WAIT`时，底行显示`X/F/R`：`X`是UART收到的原始字节数，`F`是收到换行后尝试解析的完整行数，`R`是被格式、校验或范围检查拒绝的行数。`X=0`优先检查接线；`X>0,F=0`优先检查换行和帧头；`F>0,R>0`说明格式或校验不合格。
